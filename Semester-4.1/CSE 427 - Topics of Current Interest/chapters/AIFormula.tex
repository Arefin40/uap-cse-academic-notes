\textbf{Triangular Membership Function:}\\[0.5em]
$\mu_A(x) =
\begin{cases} 0 & \text{if } x < a \text{ \ or \ } x > b \\
   \frac{x-a}{m-a} & \text{if } a \leq x \leq m \\[1em]
   \frac{b-x}{b-m} & \text{if } m < x \leq b \\
\end{cases}$

\topic{Uncertainty}
$P(A \cup B) = P(A) + P(B) - P(A \cap B)$

Bayes' theorem: $P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$

Conditional Probability: $P(A|B) = \frac{P(A \cap B)}{P(B)}$

$X$,$Y$ independent if and only if:: $\forall x,y : P(x,y) = P(x)P(y)$

$X$ and $Y$ are conditionally independent given $Z$ i.e. $X \bigCI Y | Z$ if and only if: $\forall x,y,z : P(x,y|z) = P(x|z)P(y|z)$

\textbf{Variables:}\\[0.5em]
$P(Q|e_1, e_2, \ldots, e_n)$\\[0.5em]

Evidence variables $(e)$: The variables that are observed or known\\
Hidden variables $(H)$: The variables that are neither query nor evidence just provides additional data.
