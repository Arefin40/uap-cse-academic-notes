\makecell{\textbf{K-Means}}
& \makecell{\textbf{KNN}}
& \makecell{\textbf{Decision Tree}}
\\\hline

K-means clustering is an unsupervised machine learning algorithm used to partition $N$ data points into a pre-defined number of $K$ non-overlapping clusters.
&
Finds the k nearest neighbors and predict the class by the majority vote of the nearest neighbors. Its a lazy learning model i.e it requires no training.
&
Recursively splits data based on feature values to create a tree-like model, where nodes represent decisions and leaves represent outcomes or class labels.

\topic{Naive Bayes}
A probabilistic classifier based on Bayes' theorem, assuming all features are conditionally independent of each other, given the class. \\
\textbf{Pros:} Extremely fast, Easy to implement, Performs well on text classification \\
\textbf{Cons:} Unreliable probability estimates, Assumes features are independent , Zero Frequency Problem
