\subsection*{Problem Statement}

The problem is to implement the classic game of Tic Tac Toe as an adversarial search problem. The goal is to design an AI player capable of making optimal moves by applying the Minimax algorithm with Alpha-Beta pruning. The AI should evaluate possible game states to choose the best action and ensure optimal play against either a human or another AI. Additionally, the efficiency of the algorithm and the effect of scoring on AI behavior need to be analyzed.


\subsection*{Approach and Implementation}
\begin{enumerate}[itemsep=1em]
    \item \textbf{Game Implementation}
    \begin{itemize}[itemsep=0.5em, topsep=1em]
        \item A 3x3 Tic Tac Toe board was implemented using a Python list to represent the state of the grid.
        \item Console output was used to print the board after each move.
    \end{itemize}
    \item \textbf{Adversarial Search (Minimax)}
    \begin{itemize}[itemsep=0.5em, topsep=1em]
        \item The Minimax algorithm was implemented to recursively evaluate all possible game states.
        \item The maximizing player (X) aims to maximize the score, while the minimizing player (O) tries to minimize it.
        \item Terminal states were assigned scores: +1 (X wins), -1 (O wins), 0 (draw).
    \end{itemize}
    \item \textbf{Alpha-Beta Pruning}
    \begin{itemize}[itemsep=0.5em, topsep=1em]
        \item $\alpha$ (best guaranteed score for maximizer) and $\beta$ (best guaranteed score for minimizer) were applied to prune branches where $\beta \leq \alpha$.
        \item This reduced the number of explored nodes, which makes the algorithm more efficient.
    \end{itemize}

    \item \textbf{Experiment Setup}
    \begin{itemize}[itemsep=0.5em, topsep=1em]
        \item Multiple test board states were used to compare outcomes.
        \item Node exploration counts were tracked to measure efficiency.
    \end{itemize}
\end{enumerate}

\subsection*{Alpha Beta Pruning}
\begin{minipage}{0.48\textwidth}
   \begin{figure}[H]
      \includegraphics[width=\linewidth]{figures/alpha-beta.png}
   \end{figure}
\end{minipage}
\begin{minipage}{0.51\textwidth}
   \begin{itemize}[itemsep=0.5em]
      \item Initialize $\alpha = -\infty$ and $\beta = +\infty$
      best value found so far.
      \item Traverse the game tree using DFS.
      \item At each maximizer node:
         \begin{itemize}[leftmargin=2em]
            \item Update $\alpha$ if a better max value is found.
            \item Prune remaining children if $\beta \leq \alpha$.
         \end{itemize}
      \item At each minimizer node:
         \begin{itemize}[leftmargin=2em]
            \item Update $\beta$ if a better min value is found.
            \item Prune remaining children if $\beta \leq \alpha$.
         \end{itemize}
      \item Return the static evaluation (leaf value).
   \end{itemize}
\end{minipage}

\subsection*{Results and Observations}
\begin{itemize}
    \item In all evaluated test cases, the AI consistently identified the optimal move.
    \item Under conditions of optimal play from both participants, the game invariably concluded in a draw, thereby validating the correctness of the implementation.
    \item Furthermore, the incorporation of Alpha-Beta pruning led to a substantial reduction in the number of nodes explored relative to the standard Minimax algorithm.
\end{itemize}

\vspace{1em}
\subsection*{Challenges}
\begin{itemize}
    \item \textbf{Correct pruning logic:} ensuring $\alpha$ and $\beta$ updates were implemented properly.
    \item \textbf{Move ordering:} efficiency of pruning varied depending on exploration order.
    \item \textbf{Tie-breaking:} In scenarios where multiple moves were evaluated as equally optimal, the algorithm picked the first move encountered during its search process.
\end{itemize}

\vspace{1em}
\subsection*{Conclusion}
The implementation of \textbf{Minimax with Alpha-Beta pruning} successfully produced an optimal Tic Tac Toe AI. 
The algorithm ensures optimal play and never loses against any opponent. 
Alpha-Beta pruning greatly reduces computation without affecting correctness. 

For a simple game like Tic Tac Toe, the approach works perfectly and demonstrates the strength of adversarial search. 
This experiment confirms that adversarial search is a powerful technique for two-player zero-sum games and forms 
the foundation for more complex AI systems in games such as Chess or Go.
