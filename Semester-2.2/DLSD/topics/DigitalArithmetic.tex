\Question{What is a Combinational circuit?}
A combinational circuit is one in which we combine the various different gates to form a circuit. The output of the combinational circuit is determined by the present inputs, regardless of the previous inputs.

\Question{What is a Sequential circuit?}
A sequential circuit is one in which previous state output is used as the input to the next component. It also has memory elements.
There are two types of sequential circuits

\vspace{-1ex}
\begin{enumerate}[label=(\alph*), labelsep=0.25cm, align=right, left=0pt]
   \item Synchronous
   \item Asynchronous
\end{enumerate}


\Question{Show the differences between Combinational circuit and Sequential circuit.}
\begin{tabularx}{\textwidth}{|X|X|}\hline
   \thcx{Combinational circuit} & \thcx{Sequential circuit}\\\hline
   In Combinational Circuit, output depends on the present state only.
   & In Sequential Circuit, output depends on present state as well as the past state.\\\hline
   Does not require any memory element to store the output.
   &  Requires a memory element to store the previous state output.\\\hline
   Clock signal is required.
   & Clock signal isn't required.\\\hline
   Easy to design.
   & Difficult to design.\\\hline
\end{tabularx}

\Topic{Half Adder}
Half Adder is a combinational logic circuit which is designed by connecting one \textbf{XOR} gate and one \textbf{AND} gate. The adder circuit as two inputs $A$ and $B$ which adds two binary numbers and generates a $Carry$ and $Sum$.

\Topic{Logical Expression:}
$\begin{aligned}
   \text{Sum} &= \not{A}B + A \not{B} = A \oplus B\\
   \text{Carry} &= A.B
\end{aligned}$

\Topic{Full Adder}
Full Adder is combinational logic circuit that is consist of 2 XOR gate, 2 AND gate and 1 OR gate. Full Adder performs an addition operation on three one-bit binary numbers $A$, $B$, $C_{in}$ and produces a sum of the three inputs and carry value designated as $C_{out}$.

\Topic{Logical Expression:}
$\begin{aligned}
   \text{sum\ \ }
   &= \not{A}\not{B}C_{in}+\not{A}B\not{C_{in}}+A\not{B}\not{C_{in}}+ABC_{in}\\
   &= \not{A}\left(\not{B}C_{in}+B\not{C_{in}}\right) + A \left(\not{B}\not{C_{in}}+BC_{in}\right)\\
   &= \not{A}\left(B \oplus C_{in}\right) + A \left(\not{B \oplus C_{in}}\right)\\
   &= A \oplus B \oplus C_{in}
\end{aligned}$

$\begin{aligned}
   \text{carry}
   &= \not{A}BC_{in}+A\not{B}C_{in}+AB\not{C_{in}}+ABC_{in}\\
   &= C_{in}\left(\not{A}B+A\not{B}\right) + AB \left(\not{C_{in}}+C_{in}\right)\\
   &= C_{in}\left(A \oplus B\right) + AB\\
\end{aligned}$
