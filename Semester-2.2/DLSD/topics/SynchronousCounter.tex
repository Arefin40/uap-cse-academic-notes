\Section{Synchronous Counter}
\vspace{2em}

\Question{Define Asynchronous counter?}
The counter where all the outputs do not response together, that counter is called asynchronous counter or ripple counter.

\Question{Define Synchronous counter?}
The counter where all the outputs response together, that counter is called asynchronous counter or parallel counter.

\HeadingCenter{Propagation Delay}
% Propagation delay in a logic gate refers to the time it takes for the output signal to respond to a change in the input signal.

For any device, to give the input, and response for output, it takes some time, this time is
called propagation Delay.

\begin{center}
   $\begin{array}{lll}
      J.K \text{ FF } & \Rightarrow &tpd \ = \ 50ns \ = \ 50\times 10^{-9} {s}\\
      \text{AND gate } & \Rightarrow &tpd \ = \ 20ns \ = \ 20\times 10^{-9} {s}\\
   \end{array}$
\end{center}


\begin{tabular}{ll}
   For asynchronous counter: &
   Total \ $tpd \ = \ tpd$ for one $J.K$  FF $ \ \times \ $ Number of FF\\
   For synchronous counter: &
   Total \ $tpd \ = \ tpd$ for one $J.K$  FF $ \ + \ \ tpd$ for one AND gate\\
\end{tabular}
